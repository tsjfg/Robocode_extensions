# 麦轮底盘扩展（MecanumWheelExt26Z）

四轮麦克纳姆轮（麦轮）图形化扩展，格式与桌面「舵机狗」案例完全一致：`config.json` + `index.js`。生成 Python 代码，驱动方式按 zmrobo 官方文档《麦克纳姆轮驱动》的角度公式实现。

## 导入方式

1. 把整个「麦轮扩展」文件夹放到平台扩展目录（和「舵机狗」放一起）。
2. 图形化编辑器里刷新/重启后，积木栏出现绿色「麦轮底盘」分类。
3. 程序第一条**必须**放「初始化麦轮底盘」——Python 运行时（`mc_*` 函数们）由它注入。

## 积木清单（15 块）

| 积木 | 生成的调用 | 说明 |
|---|---|---|
| 初始化麦轮底盘 | `mc_setup()` | 定义全部运行时 + 电机停车，第一条执行 |
| 设置最大速度 | `mc_set_max(v)` | 记录用，各积木速度仍以自身参数为准 |
| 标定 轮径/编码器线数/每度行驶 | `mc_calib(r,n,c)` | 闭环距离/转向标定 |
| 四轮方向修正 | `mc_dir_fix(a,b,c,d)` | 某轮装反了填 -1，不用改公式 |
| 灰度反色 | `mc_set_inv(v)` | 黑线/白底切换（对应 LineColor） |
| 停车 | `mc_stop()` | 四轮立即停 |
| 按角度移动 速度/方向 | `mc_angle(sp,a)` | **官方公式**：0°前进、90°纯侧移，任意角度斜移 |
| 直行 速度/距离 | `mc_move(0,s,d)` | 编码器闭环 + 梯形加减速 + 四轮同步纠偏 |
| 侧移 速度/距离 | `mc_move(1,s,d)` | 同上，侧移按对角轮分组纠偏 |
| 斜移 速度/距离/旋转分量 | `mc_move_kt(s,d,kt)` | 斜移同时叠加旋转分量（边横走边转） |
| 转向 速度/角度 | `mc_turn(s,a)` | 编码器闭环原地转，带缓入缓出 |
| 运动到灰度 模式/速度/传感器/超时 | `mc_until(...)` | 直行/侧移/原地转到指定灰度探头停，**带超时** |
| 巡线 速度/kp/kd | `mc_line_pd(...)` | PD 巡线单步（放"重复执行"里用） |
| 巡线 速度/kp/kd/持续秒 | `mc_line(...)` | 限时巡线，自动停 |
| 巡线到传感器 | `mc_line_until(...)` | 巡到指定探头停，**带超时** |

## 轮号约定（与官方文档一致）

1 = 左前 FL，2 = 右前 FR，3 = 左后 BL，4 = 右后 BR。
角度公式：FL/BR = v·(sinθ+cosθ)，FR/BL = v·(cosθ−sinθ)，0.7 系数用于归一化（45° 时峰值 1.41）。

## 标定步骤（新底盘必做）

1. 量轮半径（cm）和编码器线数 → 用「标定」积木写入。
2. 转向标定「每度行驶 cm」：让车原地转 360°，读四轮平均脉冲数，转过的弧长 ÷ 360 就是该值；默认 0.222（旧工程经验值，轮径 6cm、360 线）。
3. 某轮方向不对 → 用「四轮方向修正」把对应位置改 −1，**不要**去改公式。
4. 灰度探头极性不对 → 灰度反色开。

## 硬件 API 依赖（改平台只动一处）

所有电机/传感器调用集中在这些函数里，其余全是纯 Python 数学：

- `rcu.SetMotor(轮号, 速度)` —— 官方文档用法（语雀 jmc2108）
- `rcu.GetMotorCode(轮号)` / `rcu.SetMotorCode(轮号)` —— 编码器读写（与 C 版 `GetMotorCode/SetMotorCode` 同族）
- `rcu.GetTraceV2I2C(1, 探头号)` —— 灰度探头（与 C 版 `GetTraceV2I2C(_P1_, n)` 同族）
- `rcu.SetWaitForTime(秒)` —— 平台延时

如果 Python 绑定名与此不符，只需在 `index.js` 里搜 `rcu.` 全局替换成实际名字。

## 注意事项

- **所有闭环运动（直行/侧移/斜移/转向）内置了超时保护**（按距离/角度估算，约 `3 + 距离×0.8` 秒、`3 + 角度×0.08` 秒）：编码器失效或轮子卡住时自动退出，不会死循环。若你的车特别慢，超时误触发就适当调大 `index.js` 里的 `guard` 公式。
- "运动到灰度/巡线到传感器"另需手动给超时参数：**务必给合理值**，防止探头失效时死循环（比赛翻车重灾区）。
- 巡线 PD 已固定 10ms 周期（`mc_line_pd` 内部 `rcu.SetWaitForTime(0.01)`），kd 才能稳定工作；单步积木放在"重复执行"里用时也是这个节拍。
- 「按角度移动」是开环（无编码器、无超时），适合云台跟随/遥控方向控制，别忘了配「停车」；要精确距离请用直行/侧移/斜移闭环积木。

## 积木使用说明（15 个积木）

程序骨架（初始化必须放在最前面，它负责注入全部 `mc_*` 运行时函数和全局变量）：

```
当开机 / 主程序开始
  初始化麦轮底盘
  [标定 轮径 3 cm 编码器线数 360 每度行驶 0.222 cm]   ← 按实测车修改
  设置最大速度 100
  ...你的任务逻辑...
```

### 一、初始化与设置类（不产生运动）

| 积木 | 作用 | 要点 |
|---|---|---|
| 初始化麦轮底盘 | 注入运行时函数、清零编码器、停车 | **必须是程序第一条麦轮积木** |
| 设置最大速度 v | 全局限幅 `mc_maxspeed` |  closed-loop 积木的速度再大也被它压住 |
| 标定 轮径 r / 线数 n / 每度 c | 设置编码器距离换算与转向换算 | 轮子/编码器换了才改；每度行驶实测标定 |
| 四轮方向修正 FL FR BL BR | 某轮装反了填 −1 修方向 | 不要改公式，只改这里的 ±1 |
| 灰度反色 开/关 | 灰度探头极性反了打开 | 影响所有灰度/巡线积木 |

### 二、开环角度驱动（官方公式）

- **按角度移动 速度 s 方向 angle 度**：`mc_angle(s, angle)`，官方文档原生公式，四轮 `v·(sinθ+cosθ)` / `v·(cosθ−sinθ)` ×0.7。
  - angle：0=前进，90=侧移，180=后退，270=反向侧移（0~360 连续，可斜着走）。
  - **不阻塞、无距离概念**：适合放在「重复执行」里做遥控/云台跟随方向控制，必须配「停车」；要精确走距离请用下面的闭环积木。
  - 方向由速度符号决定（负速后退）。

### 三、闭环运动类（编码器闭环 + 梯形加减速 + 四轮同步纠偏 + 超时保护）

共同约定：**距离必须给正数，方向由"速度"的正负决定**；内置超时 `3 + 距离×0.8` 秒，编码器失效会自动退出不车死循环。

- **直行 速度 s 距离 d cm**：`mc_move(0, s, d)`，四轮同向、按平均编码器收敛，走标准直线。
- **侧移 速度 s 距离 d cm**：`mc_move(1, s, d)`，`[+,-,-,+]` 轮组，横向平移（与「按角度移动 90°」同方向）。
- **斜移 速度 s 距离 d cm 旋转分量 kt**：`mc_move_kt(s, d, kt)`，对角线两组轮差动。kt=0 是与「侧移」反向的纯斜移；kt 从 −s 到 +s 线性叠加旋转分量（kt 接近 +s 时边斜移边原地转），做弧线走位，先小值试。
- **转向 速度 s 角度 a 度**：`mc_turn(s, a)`，按 `每度行驶 c cm` 标定值折算目标里程，原地转。**正角度=逆时针（左转），负角度=顺时针（右转）**。超时 `3 + 角度×0.08` 秒。

### 四、灰度与巡线类

- **运动到灰度 模式 m 速度 s 传感器 x 超时 t 秒**：`mc_until(m, s, x, t)`，开环走到某个灰度探头触发为止。
  - 模式菜单：原地逆时针 / 原地顺时针 / 直行 / 侧移。
  - 传感器菜单 S1~S7（对应灰度探头号）。**超时必填合理值**，探头失效时保命。
- **巡线 速度 s kp kp kd**：`mc_line_pd` 的**单步**版本，放在「重复执行」里用；已内置 10ms 固定周期，kd 才稳。用探头 3 和 5 的差值做误差。
- **巡线 速度 s kp kp kd 持续 sec 秒**：`mc_line(s, kp, kd, sec)`，自动循环 sec 秒后停车，一步到位。
- **巡线到传感器 x 速度 s kp kp kd 超时 t 秒**：巡线直到 x 号灰度探头触发（如路口、终点线）或超时，自动停车。

### 典型任务示例

```
初始化麦轮底盘
设置最大速度 80
直行 速度 60 距离 50        // 编码器闭环走 50cm
转向 速度 50 角度 90         // 左转 90°
巡线 速度 40 kp 8 kd 3 持续 2
运动到灰度 直行 速度 50 传感器 S4 超时 3   // 走到 4 号探头看见线
斜移 速度 50 距离 30 旋转分量 20            // 斜着绕障碍
停车
```

### 调试顺序建议

1. 先只放「初始化 + 按角度移动 + 停车」，确认四轮转向与官方角度公式方向一致（谁反了用「四轮方向修正」修）。
2. 再测「直行/侧移」闭环距离精度，不准就改「标定」里的轮径、编码器线数。
3. 标定转向：转 90° 实测差多少，反推改「每度行驶 c」。
4. 最后调巡线 kp/kd：kp 太大抖、kd 太大冲，典型从 kp=8 kd=3 起调。
